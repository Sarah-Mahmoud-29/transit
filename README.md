# Ride Booking System

A console-based Ride Booking System written in C++ applying Object-Oriented Programming (OOP) principles.

## Features
- **User Authentication:** Simple signup and login system.
- **Vehicle Fleet Management:** Dynamic calculation of trip fares for different vehicle types (Car, Bus, Scooter) using **Polymorphism** and **Inheritance**.
- **Wallet System:** Deposit money and automatically deduct trip fares upon booking.
- **Trip History:** Keep track of all completed bookings.

## Project Structure
- `models.h`: Contains all class definitions, structures, and business logic.
- `main.cpp`: Entry point of the application controlling the main menu loop.

## How to Run
Open the project in Code::Blocks or Visual Studio Code, compile `main.cpp`, and run the application.
